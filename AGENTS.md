# cad-lab-skills

Начинать с `README.md`. Основная ветка — `main`.

- Каждый каталог верхнего уровня с `skill-package.json` — самостоятельный пакет.
- Общие навыки и профессии редактируются здесь; копии в app генерируются.
- Push изменений — только в GitLab origin. Публичный GitHub обновляет push mirror
  GitLab; не заменять зеркалирование прямой публикацией в GitHub.
- Сохранять ID пакетов и имена навыков: от них зависят каталог и профессии.
- При изменении зависимостей синхронизировать `dependencies` профессии
  с декларацией в каталоге API контейнера cad-lab.
- CAD-адаптеры и технические CAD-навыки остаются в репозиториях коннекторов.
- Не добавлять токены, внутренние модели, демо или инфраструктурные настройки.
- Общие документы продукта — только в `docs/` репозитория-контейнера cad-lab.
