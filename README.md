# cad-lab-skills

Общие инженерные навыки и профессии cad-lab, независимо от CAD.
Каждая папка — отдельный устанавливаемый пакет с собственной версией.

| Пакет | Назначение | Обязательные зависимости |
|---|---|---|
| `cad-lab-design-engineer` | Профессия инженера-конструктора: организация работы и согласованность результата | Три навыка ниже |
| `cad-lab-mechanical-design` | Проектирование деталей и сборок | Нет |
| `cad-lab-drawing-preparation` | Подготовка рабочего чертежа по ЕСКД | Нет |
| `cad-lab-drawing-review` | Проверка готового чертежа и нормоконтроль | Нет |

```text
cad-lab-design-engineer/
  package.json
  server.ts
  skills/design-engineer/SKILL.md
cad-lab-mechanical-design/
cad-lab-drawing-preparation/
cad-lab-drawing-review/
```

В каждой папке `package.json` содержит имя, версию, описание, `bb.skills` и,
для профессии, `bb.dependencies`. `server.ts` — пустая точка входа формата bb;
в пакетах нет исполняемой инженерной логики, CAD-адаптеров или ключей доступа.
Ресурсы навыка находятся рядом с его `SKILL.md` в `references/`.

## Установка

Через каталог cad-lab в приложении или CLI:

```sh
bb plugin install cad-lab-design-engineer@cad-lab --yes
bb plugin install cad-lab-drawing-review@cad-lab --yes
```

Профессия автоматически устанавливает три обязательных навыка отдельными
пакетами. Любой навык доступен самостоятельно. CAD выбирается отдельно;
установка профессии не устанавливает КОМПАС, FreeCAD или другой адаптер.
Требуется версия приложения cad-lab с поддержкой `bb.dependencies`.

Для локальной разработки можно установить путь к папке пакета:

```sh
bb plugin install path:/work/cad-lab-skills/cad-lab-design-engineer --yes
```

Недостающие зависимости найдутся в соседних папках с именами ID пакетов.

## Сопровождение

Это канонический источник общих навыков и манифестов пакетов. В контейнере
cad-lab репозиторий подключён сабмодулем `cad-lab-skills/`. Сборка приложения
обновляет поставляемые копии командой `npm run prepare:skills` из `app/`.
Копии внутри `app/bb/plugins/cad-lab-*` не редактируются вручную.

Основная ветка — `main`. Каталог указывает на подпапку соответствующего пакета
в этом репозитории. Версии пакетов меняются независимо; при изменении требований
профессии обновляются её `bb.dependencies` и декларация в каталоге API.

Репозиторий предназначен для последующего зеркалирования в GitHub.
В нём нет CI, инфраструктуры, внутренних демо и ссылок на приватные сервисы
в инструкциях навыков. Лицензии пакетов сохранены как `UNLICENSED`;
открытая лицензия этим переносом не назначается.

Документация продукта и решения по установщику хранятся в `docs/` контейнера cad-lab.
