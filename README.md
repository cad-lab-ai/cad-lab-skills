# cad-lab-skills

Общие инженерные навыки и профессии cad-lab, независимо от CAD и плагинов.
Каждый каталог верхнего уровня — отдельный пакет со своей версией.

| Пакет | Тип | Обязательные зависимости |
|---|---|---|
| cad-lab-design-engineer | Профессия инженера-конструктора | Три навыка ниже |
| cad-lab-mechanical-design | Проектирование деталей и сборок | Нет |
| cad-lab-drawing-preparation | Подготовка чертежей | Нет |
| cad-lab-drawing-review | Проверка чертежей | Нет |

Пакет содержит декларативный `skill-package.json` и
`skills/<имя-навыка>/SKILL.md` с соседними ресурсами. Манифест задаёт
schemaVersion, id, version, kind (skill/profession), displayName, description,
skill и dependencies (name/version). Исполняемого сервера и манифеста плагина нет.

## Установка

В приложении: «Скиллы» → каталог → выбранный навык или профессия.

`bb skill package install cad-lab-design-engineer`

`bb skill package install cad-lab-drawing-review`

Профессия автоматически устанавливает обязательные навыки отдельными пакетами.
Любой навык можно установить самостоятельно; CAD-адаптеры устанавливаются отдельно
через «Плагины». Удаление профессии сохраняет навыки. Отключение или удаление
обязательного навыка при включённой профессии блокируется с объяснением.

Команды `bb skill package list|update|enable|disable|remove` управляют теми же
пакетами, что интерфейс. SDK: `sdk.skills.packages.list()` и
`sdk.skills.packages.change({ id, action })`.
Для локальной разработки задайте серверу `BB_SKILL_PACKAGES_ROOT` — путь к этому
репозиторию. Сетевой каталог задаётся `BB_SKILL_PACKAGE_CATALOG_URL` и указывает
на каждый пакет отдельно (Git URL, ref, subdir). Версии выпускаются независимо.

## Сопровождение

Канонические исходники находятся здесь; сборка приложения обновляет резервные
копии в `app/bb/skill-packages` командой `npm run prepare:skills`.
Копии не редактируются вручную. Основная ветка — main. ID и имена навыков сохраняются.
При изменении версии и зависимостей обновляется отдельный каталог
`api/src/skill-catalog.json`; каталог плагинов не содержит этих пакетов.

Источник изменений — GitLab. Push выполняется только туда; публичная копия
[cad-lab-ai/cad-lab-skills](https://github.com/cad-lab-ai/cad-lab-skills)
обновляется push mirror. Перед выпуском проверяется совпадение коммитов.
Лицензия остаётся UNLICENSED. Общие документы продукта — в docs/ контейнера cad-lab.
